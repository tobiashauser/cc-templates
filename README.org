#+title: cc-templates
#+author: Tobias Hauser

This flakes defines multiple templates for new cobweb-curriculum packages.

** Usage

Show all defined templates:

#+begin_src bash
  nix flake show "git+ssh://git@github.com/tobiashauser/cc-templates"
#+end_src

Install a template in the current directory with:

#+begin_src bash
  nix flake init -t "git+ssh://git@github.com/tobiashauser/cc-template"#NAME
#+end_src

** Templates

This flake defines templates for various types of packages. Although naturally not every
usecase can (and should) be covered. Most of the templates are designed in such a way that you
can combine multiple.

*** lib

Defines a new cobweb-curriculum package that exports library functions.
